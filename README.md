# Мій зошит з української — платформа для учнів і вчителя

Інтерактивна платформа для річного курсу «Українська мова, 4–5 клас».
36 уроків, кожен ≈ 60 хв, поєднує лексику й граматику. Тепер кожен учень
заходить під своїм іменем, проходить уроки з будь-якого пристрою, а
вчитель бачить прогрес і виконання ДЗ усіх учнів на одній сторінці.

## Структура репозиторію

```
index.html            — головна сторінка зі списком уроків (вимагає входу)
login.html            — вхід учня: обрати своє ім'я зі списку
lessons/
  lesson-01.html       — Урок 1 (готовий)
  lesson-02.html       — Урок 2 (готовий)
  lesson-03.html       — Урок 3 (готовий)
teacher/
  index.html           — вчительська панель з результатами всіх учнів
assets/
  style.css            — спільний дизайн
  lesson-kit.js         — флеш-картки, конструктор речення, вправи, ДЗ-чекліст
  platform.js           — вхід учнів, збереження прогресу в Firestore
  students.js           — СПИСОК УЧНІВ (редагуйте тут!)
  firebase-config.js     — ключі вашого Firebase-проєкту + код доступу вчителя
```

## Крок 1. Додайте учнів

Відкрийте `assets/students.js` і впишіть реальні імена:

```js
window.PLATFORM_STUDENTS = [
  "Марійка",
  "Тарас",
  "Оленка"
];
```

Пароль не потрібен — учень просто натискає своє ім'я на сторінці входу.
Якщо захочете надійніший вхід (PIN-код), напишіть — це можна додати пізніше.

## Крок 2. Налаштуйте безкоштовний Firebase (щоб прогрес зберігався і був видний вам)

Без цього кроку сайт працюватиме, але прогрес учнів **не** зберігатиметься
онлайн і вчительська панель буде порожньою.

1. Перейдіть на https://console.firebase.google.com і створіть новий проєкт
   (можна безкоштовно, кнопка «Додати проєкт»).
2. У проєкті натисніть значок `</>` («Веб-застосунок»), дайте йому назву,
   Firebase покаже об'єкт `firebaseConfig` із кількома рядками —
   скопіюйте їх.
3. Вставте ці значення в `assets/firebase-config.js` замість прикладів
   (`ВАШ_apiKey` і т.д.).
4. У лівому меню Firebase відкрийте **Build → Firestore Database** →
   «Create database» → оберіть будь-який регіон → режим **test mode**
   (для 4–10 учнів приватної групи цього достатньо).
5. У тому ж файлі `assets/firebase-config.js` задайте свій код доступу
   до вчительської панелі:
   ```js
   window.TEACHER_PASSCODE = "мій-власний-код";
   ```

## Крок 3. Публікація на GitHub Pages

1. Завантажте цю теку у свій репозиторій на GitHub.
2. **Settings → Pages** → гілка `main`, папка `/ (root)` → зберегти.
3. Сайт буде доступний за адресою
   `https://<ваш-нікнейм>.github.io/<назва-репозиторію>/`.
   Учні заходять на цю адресу й одразу бачать сторінку входу.
   Вчительська панель — за адресою `.../teacher/`.

## Як додати новий урок (4, 5, 6…)

1. Скопіюйте `lessons/lesson-03.html` у `lessons/lesson-04.html`.
2. Замініть текст, слова (`vocab`), речення для конструктора
   (`initOrderBuilder`), вправи й мінітекст, і `id="hw-list"` — пункти ДЗ.
3. У кінці інлайн-скрипту (де вже є рядки на кшталт
   `LessonKit.initChecklist('#hw-list');`) залиште рядок:
   ```js
   Platform.initLessonPage('lesson-04', 'Урок 4. Назва теми');
   ```
   (номер і назва — саме ті, що будуть показані вчителю в панелі).
4. Додайте урок у список `Platform.LESSONS` у файлі `assets/platform.js`:
   ```js
   { id: 'lesson-04', title: 'Урок 4. Назва теми', file: 'lesson-04.html' }
   ```
5. У `index.html` додайте назву й тему граматики в масив `lessons`,
   і збільште умову `ready` (`n <= 4`), щоб новий урок відкрився в списку.

## Що бачить учень

- Заходить на сайт → сторінка входу → обирає своє ім'я (без пароля).
- Бачить список уроків, проходить вправи, зірки за виконані завдання
  та чекліст ДЗ унизу кожного уроку зберігаються автоматично.
- Може зайти з іншого пристрою (телефон, комп'ютер) під тим самим
  іменем — прогрес підвантажиться з хмари.

## Що бачить вчитель

- Відкриває `.../teacher/`, вводить код доступу (заданий у кроці 2).
- Бачить таблицю: рядки — учні, колонки — уроки, у кожній клітинці —
  кількість зірок і статус ДЗ («виконано» / «3/6» / «не розпочато»).
- Клік на назву уроку у заголовку таблиці відкриває цей урок в новій
  вкладці — зручно показати учневі й пройти разом (наприклад, на
  онлайн-уроці зі спільним екраном).

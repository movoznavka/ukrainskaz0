# Мій зошит з української

Інтерактивна платформа для річного курсу «Українська мова, 4–5 клас» —
для учня зі слабким словниковим запасом. 36 уроків, кожен ≈ 60 хв,
поєднує лексику й граматику: нові слова → повторення → граматика →
практика → мінітекст → робота з текстом → домашнє завдання → 5 слів
для запам'ятовування.

## Структура репозиторію

```
index.html            — головна сторінка з переліком усіх 36 уроків
lessons/
  lesson-01.html       — Урок 1: Моє повсякденне життя (готовий)
  lesson-02.html       — наступний урок (додасте самі за тим самим шаблоном)
  ...
assets/
  style.css            — спільний дизайн «зошита в клітинку»
  lesson-kit.js         — спільні інтерактивні елементи:
                          флеш-картки, конструктор речення,
                          вправи з вибором відповіді, чек-лист ДЗ
```

## Як додати новий урок

1. Скопіюйте `lessons/lesson-01.html` у `lessons/lesson-02.html` (і так далі).
2. Замініть текст, слова (`vocab`, `review`), речення для конструктора
   (`initOrderBuilder`) та мінітекст.
3. Додайте назву уроку й тему граматики у масив `lessons` в `index.html`,
   а рядок з номером зробіть `ready` (це стається автоматично, коли
   номер уроку дорівнює позиції у списку і файл `lesson-XX.html` існує —
   просто заміните умову `n === 1` на потрібну, наприклад `n <= 2`).

## Публікація на GitHub Pages

1. Завантажте цю теку у свій репозиторій на GitHub.
2. У налаштуваннях репозиторію відкрийте **Settings → Pages**.
3. Оберіть гілку `main` і папку `/ (root)`, збережіть.
4. Через кілька хвилин сайт буде доступний за адресою
   `https://<ваш-нікнейм>.github.io/<назва-репозиторію>/`.

## Джерела зображень

Фотографії у Уроці 1 — з Wikimedia Commons (вільна ліцензія), підключені
напряму через `Special:FilePath`. Для дій, які важко сфотографувати
(прокидатися, одягатися, лягати спати), використано прості піктограми
в стилі малюнків із зошита.
